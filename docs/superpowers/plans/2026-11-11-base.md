# TrackCam Base Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Uma app de iPhone que grava o jogo inteiro e mantém um jogador escolhido no centro, comandando um DJI Osmo Mobile 8 pelo DockKit, com correção por toque.

**Architecture:** A lógica de seguimento é TypeScript puro em `src/tracking/` (testada com Jest, sem telemóvel). Um frame processor em worklet deteta pessoas na imagem inteira e num recorte à volta do alvo e entrega as deteções ao seguidor; o resultado vai para o Osmo através do módulo nativo local `modules/trackcam-dock` e para o ecrã. A gravação corre em paralelo, em segmentos de 180 s guardados na app Fotografias.

**Tech Stack:** Expo SDK 58, React Native 0.88, Expo Router, `react-native-vision-camera` 5 (+ resizer, worklets), `react-native-fast-tflite`, `expo-media-library`, `expo-file-system`, Swift + DockKit, Jest (`jest-expo`), ESLint (`expo lint`).

**Spec:** `docs/superpowers/specs/2026-11-11-base-design.md`

## Review Focus

1. **O alvo sai da imagem pela borda** enquanto o Osmo roda: espera-se "perdido", não um salto para a pessoa mais próxima da borda. Teste na Tarefa 4.
2. **Vários frames seguidos sem nenhuma deteção** (pouca luz, modelo falha): espera-se previsão e depois "perdido", sem `NaN` nem exceção. Teste na Tarefa 4.
3. **Toque numa caixa que entretanto mudou de sítio na lista**: o toque resolve-se pelas coordenadas da caixa tocada, não pelo índice. Teste na Tarefa 4 (`pick`).
4. **Guardar em Fotografias falha** (permissão negada, sem espaço): o ficheiro local não é apagado e o ecrã diz onde ficou. Teste na Tarefa 6 (`nextAction`).
5. **O Osmo desliga-se a meio** (bateria, módulo encaixado): a gravação e o seguimento no ecrã continuam, o indicador muda, e ao voltar o Osmo retoma sem novo toque. Verificação manual na Tarefa 11.

```ts
// config.ts
export const TRACK = {
  alpha: 0.6, beta: 0.2,          // filtro de posição / velocidade
  sizeSmoothing: 0.3,
  gateDiagonals: 1.5,             // raio de procura = 1.5 diagonais da caixa...
  gateMin: 0.08, gateMax: 0.35,   // ...entre estes limites (fração da largura)
  gateGrowthPerSec: 2,            // o raio cresce enquanto prevê sem ver
  areaRatioMin: 0.5, areaRatioMax: 2,
  clearlyDifferent: 0.35,         // semelhança abaixo disto: não é ele
  weightMotion: 0.5, weightLook: 0.3, weightSize: 0.2,
  coastMs: 1200,                  // tempo máximo a prever sem ver
  velocityDamping: 0.9,
  referenceBlend: 0.05,           // só quando há um único candidato
  reacquireSimilarity: 0.6, reacquireMargin: 0.1, reacquireFrames: 3,
  edgeMargin: 0.02,                // centro previsto a menos disto de uma borda = a sair da imagem
  edgeGate: 0.05,                  // nesse caso só conta quem estiver mesmo em cima da previsão
} as const

// tracker.ts
export interface PersonDetection { box: Box; score: number; look: number[] }
export type TrackStatus = 'idle' | 'tracking' | 'coasting' | 'lost'
export interface TrackState {
  status: TrackStatus
  box: Box | null                 // melhor estimativa atual (vista ou prevista)
  velocity: Point                 // por segundo
  reference: number[] | null      // assinatura de referência
  unseenMs: number
  candidate: { box: Box; frames: number } | null // para readquirir
}
export const IDLE: TrackState
/** O dono tocou neste ponto do ecrã (0..1). Devolve o estado com o novo alvo, ou o mesmo estado se não tocou em ninguém. */
export function pick(state: TrackState, detections: PersonDetection[], at: Point): TrackState
export function drop(): TrackState
/** Avança um frame. `dtMs` é o tempo desde o frame anterior. */
export function step(state: TrackState, detections: PersonDetection[], dtMs: number): TrackState
```

**Regras de `step`** (o algoritmo que as assinaturas não determinam):

1. `idle`: devolve o estado tal como está.
2. `tracking` / `coasting`:
   - Prever: `centro += velocity * dt`. Raio = `diagonal(box) * gateDiagonals * (1 + gateGrowthPerSec * unseenMs / 1000)`, limitado a `[gateMin, gateMax]`.
   - Se o centro previsto estiver a menos de `edgeMargin` de uma borda, ou fora da imagem, o raio passa a ser `edgeGate`.
   - Candidatos: deteções cujo centro dista menos que o raio do centro previsto, com razão de áreas em `[areaRatioMin, areaRatioMax]` e `similarity(look, reference) >= clearlyDifferent`.
   - Pontuação = `weightMotion * (1 - dist/raio) + weightLook * semelhança + weightSize * min(razão, 1/razão)`. Ganha a maior.
   - Com vencedor: `status = 'tracking'`, posição e velocidade atualizadas pelo filtro alfa-beta, tamanho suavizado, `unseenMs = 0`. Se havia **um só** candidato, `reference = blend(reference, look, referenceBlend)`.
   - Sem vencedor: `status = 'coasting'`, `box` avança pela previsão, `velocity *= velocityDamping`, `unseenMs += dtMs`. Passa a `lost` quando `unseenMs > coastMs`, **ou de imediato** se o centro previsto estiver a menos de `edgeMargin` de uma borda ou fora da imagem.
3. `lost`: `box` fica na última posição, `velocity = 0`. Procura em **todas** as deteções a de maior semelhança com `reference`. Conta como candidata se a semelhança for `>= reacquireSimilarity` e exceder a segunda melhor por `reacquireMargin`. Se for a mesma do frame anterior (`iou >= 0.3`), `frames += 1`; senão recomeça em 1. Ao chegar a `reacquireFrames`, volta a `tracking` com essa caixa e `velocity = 0`.

`pick` escolhe, entre as deteções cuja caixa contém o ponto, a de centro mais próximo do ponto; define `reference = look`, `velocity = 0`, `status = 'tracking'`.
